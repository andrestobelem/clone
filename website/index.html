Agent skill

Teach Codex and Claude
how Clone works.

Install one shared skill in the repository where your agents work. It gives each agent a stable identity and a verified workflow for reading and changing workspace records.

01

Start Clone

Use the global workspace by default. Add --local when the repository needs its own workspace.

npx @andrestobelem/clone@0.4.0
02

Install the skill

The installer configures the same skill for Codex and Claude Code.

npx skills add andrestobelem/clone --skill clone-workspace --agent codex claude-code -y
03

Ask the agent

The agent checks the workspace, selects its actor identity, reads the current revision, performs the action, and verifies the result.

“Use Clone to create an issue for the login error.”

What gets installed

One skill, two agent paths.

Codex discovers .agents/skills/clone-workspace. Claude Code discovers .claude/skills/clone-workspace. The installer also writes skills-lock.json so the project can update the skill later.

your-project/
├── .agents/skills/clone-workspace/
├── .claude/skills/clone-workspace/
└── skills-lock.json

What the skill does

A verified operating contract.

  1. Selects global storage or the repository's .clone/ directory.
  2. Registers a stable codex or claude actor.
  3. Checks workspace health with doctor.
  4. Reads records and their revisions before each change.
  5. Uses cursor pagination and atomic batch operations.
  6. Checks the saved result and synchronization state.
  7. Recovers conflicts without losing another agent's work.

Invoke it explicitly with $clone-workspace, or ask the agent to use Clone. Update it with npx skills update clone-workspace.

The local contract

You own the work.
Clone holds the shape.

01

One process

The browser UI, CLI, and scheduler use the same TypeScript actions and local records.

02

One workspace per repository

Run Clone with --local. SQLite, snapshots, attachments, and backups stay in that repository's .clone/ directory.

03

Complete snapshots

Stable JSON snapshots make records reviewable, portable, and compatible with Git.

04

Loopback only

The server binds to 127.0.0.1 by default. Clone is personal software, not a hosted collaboration service.
