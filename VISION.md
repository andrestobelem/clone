# Vision

We want local software to be a practical default for serious project work.

A person must be able to start Clone with one command, understand where the records are, and keep working without an account or external service. A software agent must be able to use the same workspace with a persistent identity and the same safety rules.

Clone will be a small, dependable workspace that can move with its owner. Its records will remain accessible, portable, and useful beyond one interface or one execution environment.
